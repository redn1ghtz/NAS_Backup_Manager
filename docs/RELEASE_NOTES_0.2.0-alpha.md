# NAS Backup Manager 0.2.0-alpha

Обновление относительно **0.1.0-alpha**. Это предварительная альфа-версия для Windows.

## Добавлено

- Резервное копирование в **OneDrive и Dropbox** через rclone: вход в браузере,
  автоматическое создание конфигурации, локальный рабочий кэш или вторичная копия.
- Место в облаке с названием провайдера, процентом, использованным/свободным/общим
  объёмом и ручным обновлением; облачная квота отображается перед локальным диском.
- **SHA-256-проверка целостности** существующих копий и архивов с прогрессом,
  счётчиком проверенных данных, оценкой времени и отменой. Значение 0 отключает
  ограничение скорости проверки.
- **Клиентское шифрование age**, автоматическое создание ключей, экспорт отдельного
  файла восстановления и расшифровка. Шифрование включается отдельно для задачи.
- Повторы при временных сбоях с экспоненциальной задержкой; незашифрованная локальная
  передача может продолжиться с подтверждённого смещения, пока worker работает.
- **Telegram и SMTP**: общие настройки аккаунтов, независимый выбор каналов в задачах,
  явный импорт старых параметров из выбранной задачи.
- Защита облачных токенов и секретов уведомлений через DPAPI текущего пользователя Windows.
- Форматированные отчёты на русском/английском: жирные подписи, читаемый объём,
  длительность в часах/минутах/секундах и дата завершения с часовым поясом.
  Тема письма содержит название задачи и результат; письмо содержит HTML-версию и обычный текст для совместимости.

## Исправлено и улучшено

- Прогресс облачной передачи учитывает фактически отправленные байты и не показывает
  завершение до окончания операции. Состояние восстанавливается после открытия интерфейса.
- Главная страница компактнее и адаптируется к окну; списки используют собственную прокрутку.
- Цвета операций: новые — зелёные, изменённые — жёлтые, удаление — красное.
- При копировании убраны лишние выделения памяти для состояния прогресса на каждом блоке;
  отмена проверяется с прежней частотой, прогресс продолжает обновляться.
- Установщики обеих разрядностей теперь включают age, age-keygen, rclone,
  необходимые лицензионные уведомления и инструкции по получению исходников утилит.

## Как обновиться

1. Дождитесь завершения операций, отключите расписания, закройте программу.
2. Сохраните отдельную копию **всей папки настроек**: `data/` для portable либо
   `%APPDATA%\org.nasbackupmanager.desktop` для установленной версии.
3. Установленная версия: запустите новый установщик в прежнюю папку.
   Portable: распакуйте новый комплект в прежнюю папку, сохранив `data/`.
   Обновляйте все EXE, `tools/` и `licenses/` вместе.
4. Проверьте задачи и предпросмотр, включите расписания заново.

База мигрирует до **схемы 13**. Старую версию нельзя запускать с обновлённой базой;
для отката восстановите сохранённую до обновления папку настроек.
DPAPI-секреты привязаны к пользователю/ПК. Закрытый ключ age храните отдельно.

## Файлы

- `…-setup-x64.exe` / `…-setup-x86.exe` — установщики с русским/английским языком.
- `…-portable-x64.zip` / `…-portable-x86.zip` — запуск без установки.
- `…-inno-scripts.zip` — скрипты Inno Setup 7.
- `…-third-party-licenses.zip` и `…-tool-sources.zip` — лицензии и исходники
  соответствующих зависимостей age/rclone; сохраняйте их вместе с релизом.
- `SHA256SUMS.txt` — контрольные суммы загруженных файлов.

## Ограничения

Проверено на Windows 10 x64; x86 — под WOW64, не на отдельной 32-битной ОС.
Windows 11, Linux/macOS, реальные NAS и реальные облачные аккаунты требуют дальнейшей
проверки. Автотесты не подтверждают доставку сообщений в реальную почту/Telegram.
Нужен WebView2 Runtime; установщик его автоматически не устанавливает.
Сборки не подписаны Authenticode. Проверяйте важные сценарии на тестовых данных.
В облачном основном режиме требуется место под локальный кэш. Потеря закрытого
ключа age делает расшифровку невозможной. Перезапуск оборванной операции не гарантирует
побайтовое продолжение незавершённого облачного/зашифрованного файла.
