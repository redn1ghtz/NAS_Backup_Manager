# Third-party obligations — pre-release checklist

Original implementation: MIT, see LICENSE. Rust and frontend dependencies are
resolved in Cargo.lock and apps/desktop/package-lock.json. The publication helper
generates [the dependency metadata inventory](docs/DEPENDENCY_LICENSES.md) and a
licenses/ snapshot shipped with the publication packages. This document remains
a review checklist; metadata extraction is not a complete compliance assessment.

Direct additions: Tauri 2 (shell/build/CLI/API), Serde (IPC serialization), rusqlite
with bundled SQLite (local database), React/ReactDOM, Vite, TypeScript, Tailwind,
Lucide icons, Radix UI, CVA, clsx and tailwind-merge. shadcn Button source was
generated by the official CLI and adapted locally. Preserve upstream MIT notices
for the copied component and review all actual resolved package licenses before
distributing publicly. Bundled SQLite removes dependence on an OS SQLite install;
it adds native build work/binary size, not a separate service. No idle worker added.

Backup implementation also uses uuid (version IDs), file-id (safe OS identity API),
sha2 (streamed integrity verification), filetime (preserve mtimes), fs2 (capacity
and process locks), chrono (scheduler calendar) and the Tauri dialog plugin.
tempfile is test-only. None adds a daemon. Core buffers file bytes in fixed chunks;
SQLite stores the scan/plan rather than collecting directory trees in RAM.

Before distributing builds, resolve and commit lockfiles, enumerate direct and
transitive licenses for Rust, npm and platform libraries, retain required notices,
and review bundled assets, icons and fonts. Use the actual versions/licenses in
the resolved graph, not this list of planned technologies. Include Tauri/WebView
runtime and installer redistribution obligations for each actual release platform.

Graphify and UI UX Pro Max are local development tools, not linked into the app.
The generated graph HTML may reference external visualization assets; inspect its
licenses/network dependencies before publishing or bundling it. It is a developer
artifact, not an offline application component.

`design-reference.png` and its unchanged copy in docs/design were supplied by the
user. They are visual guidance; redistribution rights have not been independently
verified and are not granted by the original-code MIT license. Verify permission
before public redistribution. Do not bundle the reference image into the app.


Windows tray/notifications use installed Windows .NET Framework WinForms/Drawing
and WinRT notification APIs. The C# host is original project source, compiled by
Microsoft's installed .NET Framework compiler. Framework/Windows DLLs are not
copied into the portable folder. Building Windows requires that compiler; native
tray/toast presentation targets Windows x64 and x86. Review Microsoft runtime
terms separately if a future installer redistributes any system runtime.

The original C# helper is distributed explicitly as nas-backup-notify.exe, not as
an embedded executable payload. SHA-256 checks use the existing sha2 0.10 crate in
storage and its build script; no new third-party crate version or service was
introduced. GUI and CLI share one per-profile native compilation so that they
expect the same sidecar digest. The build cache is source/compiler keyed and
file-locked; Framework csc does not provide deterministic builds across clean
build directories. Notification identity setup is idempotent.

The headless CLI uses the already locked static_vcruntime 3.0.0 build helper
(MIT OR Apache-2.0), also used by Tauri, to link the MSVC runtime statically while
using Windows 10's system UCRT. No new crate version is introduced. MSVC runtime
redistribution remains subject to the installed Visual Studio license terms;
retain applicable Microsoft notices when distributing compiled binaries.
