# Сообщения об уязвимостях

Проект находится в альфа-стадии. Текущая версия — 0.2.0-alpha; гарантированного
срока поддержки и отдельной команды реагирования пока нет.

Если на вкладке Security репозитория доступна приватная отправка отчёта,
используйте её для сообщения об уязвимости:
https://github.com/redn1ghtz/NAS_Backup_Manager/security

Если эта функция недоступна, создайте Issue с заголовком «Нужен приватный канал
для сообщения об уязвимости», без подробностей эксплуатации. Дождитесь ответа
автора о способе передачи деталей. Не размещайте пароли, токены или рабочие копии
данных в открытом отчёте.

Для воспроизведения подготовьте минимальный пример на временных файлах и укажите
версию приложения, ОС, разрядность, настройки задачи и возможные последствия.
Обычные ошибки интерфейса или предложения направляйте в Issues.
